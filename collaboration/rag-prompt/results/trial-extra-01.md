# RAGプロンプト比較 追加ケース trial-extra-01 の結果

実施日: 2026-10-28。固定6ケースとは別の合成8ケース(`extra-cases/`、PR #82)× 2スタイル × 3指示(baseline / requirement-coverage-v2 / v3)× 3回 = 144回。採点表は `extra8-atomic-v1`。生成モデルは gpt-6-luna(全回答の応答modelで確認)。

**範囲の注意**: 合成8ケースの結果で、一般的な正答率ではない。3回では1〜2回分の差は揺らぎの範囲。v2・v3の指示は固定6ケースを見て作ったが、追加ケースの本文と採点表は候補指示と過去結果を見ていない別のClaudeが書いたので、固定6への過剰適合を確かめる材料になる。ただし採点表の正規表現は実回答で直した部分があり、最終判定は人が回答を読んで行った。

## 実行と費用

- 1回目の144回(extra-01〜03)は、e4・e8 の資料が本番の検索で拾われず(判定 insufficient)、モデルに資料が渡らなかったため無効にした。質問と資料を直して全144回をやり直した(extrav2-01〜03)。再実行も144回すべて成功、再試行なし。
- トークン概算の費用は、無効分約0.061ドル + 有効分約0.075ドル = 約0.136ドル(請求額ではない)。承認された約0.08ドルを超えたのは、この無効分の再実行による。
- 生の回答は `.local/` にだけ保存(コミットしない)。

## 本番の判定(status)と作者の想定の差

statusは本番経路の判定をそのまま使った。作者は e2・e3・e4・e7・e8 を partial と想定していたが、実際は(質問を直した後の)8ケースすべて grounded。固定6と同じく、本番では「一部だけ答えられる」質問でも grounded として扱われる。partial 向けの方針文(質問の一部が答えられない場合)は、この集合では試せていない。

## 読み取れること

- v3 は e1 で、6回答すべてで適用日(4月1日以降)を落とした(baseline・v2 は2/6)。固定6の v01-rule と同じ現象で、「判定の基準(登録日)を残す」指示が、適用日を押し出す。両取りが安定しない傾向は、別ケースでも再現した。
- v3 は e2 で、Aの値とBのページ数を残す回答が増えた(「資料が示す共通点・数値を述べる」の効果と見られる)。baseline・v2 は、Aを「1ページあたり7.5円」という導出値だけで答え、元の240ページ・1800円を書かない回答が多かった。導出値自体は資料から計算できる正しい値で、根拠違反ではないが、採点表の「Aの値」は満たさないと判断した。
- 結論先出し(e3-conclusion-first)は、3指示とも改善しなかった。v2・v3 で固定6では効いた「結論を先に」が、このケースでは4回答中1回しか守られない。
- 「比較できないのに優劣を言い切る」は、baseline 3、v2・v3 は各2。差は揺らぎの範囲。
- 資料にない値の作成(根拠違反)は、どの指示でもなし。e8(explain)の補足は、全 explain 回答で「補足」と表示し、資料の事実より後に置いた(固定6では補足が出なかったので、補足の評価がここで初めて可能になった)。
- 式を `$...$` で書く回答が v2 で2、v3 で2あった(e4)。表示の崩れは未確認。

## 採点表・ケースの課題

- e4・e8 は、元の質問(15分でいくら/損益分岐点はいくら)では本番の検索が資料を渡さなかった(要件判定で insufficient)。質問を「意味」と「資料でわかること」を尋ねる形に直した。資料に無い値を尋ねる型は、本番の検索の段階で止まる、というのが分かった点でもある。
- e2-a-values は導出値(7.5円)を認めるか、e4-base-unknown は「別途かかります」だけで金額が不明と言ったとみなすか、の判断が結果を左右する。上の表は、どちらも厳しい方(認めない)で数えた。
- 自動採点の取りこぼし: e4-unit-value(「12円です」)、e3-fee-same(「どちらも入場料は400円」)、e8-bep-unknown(「金額自体は資料に掲載されていません」)。パターンの直しは未着手。
- 本文と採点表は、PR #82 のブランチにそのまま置いている。

## 次の一手の案

- v3 の「判定の基準を残す」が適用日を押し出す問題は、固定6と追加ケースの両方で出た。指示の文言を調整するより、「判定基準」と「適用日」の両方を1文で書く言い方(例: 「適用日と判定の基準を同じ文で」)を1つだけ試すか、v2 を既定候補にして v3 の部分を捨てるかを決める。
- 結論先出しが効かない e3 の型は、質問が「どちらが」と「入場料は」を同時に聞く複合質問だった。1論点ずつに分けたケースを足すかを決める。
