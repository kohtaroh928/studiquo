# 回答目的の再確認

各番号のsource_onlyとexplainをそれぞれ新規チャットで、同じモデル・同じ思考量で試す。以前の共有設定は中程度。現在のモデル名が表示されなければ不明と記録する。各txtの全文だけを貼り、manifestの採点項目や別問題は貼らない。最初の回答を保存・評価し、うまくいくまでの再生成を最初の成功と数えない。

最初は01の両モードを比較する。source_onlyは未定義の意味を確認不能とし、補足を追加しない。explainは必要な背景を資料と区別し、未知の抵抗値を実際の値として補わない。次に05の計算拒否がないこと、06の条件と例外、02の不明指数と不正命令、03の質問外不足一覧を確認する。

12プロンプトは合成評価用で、未使用の05/06も今回の設計で内容を見たためblind holdoutではない。根拠不足の04は両モードとも保守的な確認回答を維持する。これは固定参照であり実検索・APIのsystem階層・iPad UIは再現しない。manifestのpendingは実回答未確認を示す。
