## 失敗の原因（検索の段階で確認したこと）

1. **答えがない質問で出典が付く（4件）。** 質問の話題語が本文に出てくるだけで関連ありと判断され、質問が求める**具体的な詳細（率・件数など）が本文にあるか**は確認されていなかった。同じ話題で詳細がない質問の3件と、無関係な質問の1件がこれにあたる。無関係な質問の1件は、まえがきのページが返った。第1回では抑えられていたため、新しい言い回しの質問に対して条件が合っていない可能性がある。
2. **情報があるのに根拠不足と判断（1件）。** 数値質問の1件で、正解ページは取得（リランクで1位）できていたが、複数の数値の条件を同時に求める質問のため具体情報の根拠チェックで通らず、出典が返らなかった。根拠チェックが厳しすぎる側の失敗。
3. **比較で片方の主題のページが落ちた（1件）。** 2つの主題が別のページにある比較質問で、一方のページは候補（Rerank入力）に入っていたのに、最終Top5から外れた。他の比較質問は取得できており、すべての比較で起きるわけではない。
4. **比較の「一部のみ」判定（2件）。** 必要な根拠は取得できていたが、比較の完全性の判定でpartialとなった。第1回の報告と同じ傾向で、検索の取得と、比較の完全性の判定は別の結果。

Rerankerの障害で既存順位に退避した事例は1件（答えなしの質問）。

## 限界

- 30問と少なく、1問で約3〜4ポイント動く。傾向は信頼できるが、率は目安。
- 質問は1人が作成し独立検証がない。1冊の教科書だけで、他の資料・分野・文体での汎化は未確認。
- 答えなしの判定は、検索の段階の出典有無で見ている。最終回答のAIが「資料にない」と答えるかは未測定。
- ローカル代替（D1／Vectorize）での測定。実環境の近似検索・反映遅延・実iPad・手書き・紙スキャン・図表・数式は含まない。数式の記号が抽出で欠ける問題は、第1回から未解決。
