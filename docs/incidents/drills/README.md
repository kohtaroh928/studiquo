# 机上訓練のシナリオ

実際には何も操作せず、RUNBOOKを見ながら**誰が・どの順に・どの画面で・何分で**動くかを声に出して確認する。目的は、手順の抜けと、止める権限が誰にあるかの確認。1回30〜60分。年に1回と、手順を大きく変えたときに行う。

進め方:
1. 進行役がシナリオの「状況」を読み上げ、1ステップずつ「次に何をしますか」と聞く。
2. 参加者はRUNBOOK(RB-10・RB-18・RB-19、付録A)を開いて答える。記憶で答えない。
3. 詰まった所(手順が無い、権限が誰にも無い、連絡先が空欄)を記録する。
4. 終わったら、見つかった抜けをRUNBOOKまたはNotionのカードに直す。
