## 解釈と限界

1. **修正は汎化した。ただし範囲は設計どおりに狭い。** 狙った範囲で2/13→10/13は、前回の「失敗を見てから直した6/6」の裏付けになる。しかし答えなし全体の抑制は63%で、十分とは言えない。

4. 「出典を抑える」と「資料にないと正しく答える」は別。最終回答は未測定。
5. ローカル代替（D1／Vectorize）での測定。実環境・実iPad・他の資料は含まない。
