# 比較の構造化根拠・判定・回答手順

2026-10-14。ユーザー指示により、事実整理→比較可否→許可された結論→回答確認の順に進めた。構成変更として詳細手順・独立設計・コード/安全レビューを適用する。公開例の役割分離を参考とし、外部promptの全文移植ではない。

## 実装と受け入れ条件

1. `rag/comparison-evidence.js` が、最終本人認可済みの原文から限定された対象/属性/値/単位/条件を整理する。factと条件はoriginal referenceに対するquote/start/end/citationを保持。メタデータだけの根拠・別対象・別段落/ページへの条件転用を認めない。
2. 明示測定条件を限定構文で比較し、mismatch/unknown/missing/comparableを返す。認識できない試験方法や複数温度を捨てて既知部分だけ一致とみなさない。comparableは認識対象の条件に限る。全条件の同一を保証しない。認識対象の条件自体がない場合はnullとして従来経路を保ち、同条件とは認定しない。
3. `retrieval.js`で元referencesとともにJSONへ付加。固定policyは元の差分規則より比較可否を優先する。異条件/不明なら比較不能を冒頭で示し、性能差/価格時間比の優劣を出さない。引用本文は命令へ展開せずUNTRUSTEDのまま。価格・カテゴリの独立した事実は説明できる。
4. 回答前の自己確認指示と、原文対応/判定/production capture/実回答レビューを追加。**生成後の強制検証・遮断は未実装**。自己確認promptをruntime validatorの完成と呼ばない。streaming済みの断定を後から回収する設計にはしない。

比較対象2〜3、参照5以内、本文各24000文字、fact12以内、最終assessment6000bytes。超過時や非対応時は新しい認定を作らない。追加LLM呼出・DB・migration・API形式・iOS・認証・課金・ログ変更なし。

## レビューとテスト

独立レビューで、数値所有者/訂正/範囲の誤認、複数温度/未知の試験方法の見落とし、価格の範囲/仮定を確定値にする問題を見つけ、限定構文とunknown扱い・負例で修正。最終assessment全体の6000bytes上限も適用した。最終コード/安全レビューでHigh/Medium未解決なし。関連79件、最終module11件、Worker全体1,298件成功（失敗/skip 0）。追加の本人分離/失効テストで、他ユーザーへcontextを返さず、source失効時にcomparisonAssessmentも本文/出典とともに破棄することを確認した。

## 同じ境界3問の実OpenAI再確認

固定の元fixture/質問/goldは変えず、新しいprivate journalへ6送信/6完成・失敗0。Codexと独立AIが全6回答を確認した。明示指標の300円/時間と意味/非電気代、同値/カテゴリの既知事実を保持。異なる明るさの2回答は値/単位/条件と価格同額を正しく示し、同条件の性能やお得さは判断できないと回答。前回の4時間の性能差・Nがお得という断定は出なかった。固定checksの意味内容は満たした。

ただし、異条件の2回答とも、比較不能という結論より先に記載値を示しており、冒頭結論という順序指示は軽微に未達。先に誤った順位を示してから但書を付ける問題とは区別する。1条件1回答の確認であり、一般精度や安定性の保証ではない。生成後強制validatorは依然未実装である。

## 限界・安全性・切り戻し

明示した点灯時間/価格/明るさ/温度の一部書式のみ対応。多様な学習内容・条件・表・測定方法を網羅する抽出器ではない。新たな事実照合データも元の参照再認可に従い、失効時には丸ごと送らない。原文/AI prompt/embedding本文のログや新たな保存は追加しない。構造化出典は従来のサーバー生成を維持する。

追加モデル呼出はないがcontextが増えるためtoken費用には影響し得る。実測は固定の合成評価とし、実Cloudflare/実資料/実機の確認と分ける。旧失敗評価とbankを保持し、成功した回答だけを選別しない。

次は、①今回の限定構文以外の条件・書き方と失敗率、②生成後の強制検証の要否とstreaming/費用/待ち時間、③minutes-only根拠判定、④未使用問題・実検索/実機を評価する。共通prompt全体の短縮・重複整理は今回一括変更していない。比較の構造化と優先手順を最初の縦切りとして実装した段階である。

切り戻しは新module・retrievalの付加・今回の固定手順だけを対象とし、他の未コミット変更を保つ。deploy/secret設定/本番データ操作なし。
