# 比較・2主題の partial：保存済み評価の一次診断

2026-10-22。対象は事前登録済みv7評価の答えあり18問のうち、shadowでpartialだった10問。新しいモデル呼び出しや質問の変更は行っていない。質問・資料本文は記録しない。

## 観察

- 保存済み結果の evidenceRecall は9問で1、1問で0.5。指定された根拠位置の取得を表し、回答に必要な文脈や別名の意味の完全性を保証しない。
- 固定manifestから各質問の `queryPlan` の `coverageGroups` を取り出し、指定された根拠のページ全体に対し `coversSubject` を照合したところ、10問すべてで少なくとも1グループが一致しなかった。うち9問は不一致グループに質問の続きとみられる表現（それぞれ、どのよう、ですか等）を含む。2問はグループ数が3になった。これは抽出誤りの有力な手掛かりだが、ページ全体を用いた診断であり実行時の抜粋そのものの再現ではない。
- 実装では `evidence.partial` が偽で、すべてのcoverage groupが支持された抜粋で `coversSubject` を満たす場合のみgrounded。shadowは回答を変えない。このため、不正な主題の抽出・文字列一致の厳しさがpartialにつながりうる。
- evidenceRecall 0.5の1問は取得側の不足も重なりうる。保存結果には最終抜粋が含まれないため、10問それぞれの確定原因や選択・検索段階の因果は未確定。

## 2026-10-23：出典ページ・候補段階まで追加診断

前回の根拠ページ照合に加え、保存済みの `stages.final` にある**実際に出典となったページ**について、元資料から現行の分割関数で全チャンクを再生成し、各チャンクとその前後の最大3チャンクを連結して、不可視文字除去・秘匿情報マスキング・6,000文字上限を適用したすべての候補抜粋に `coversSubject` を試した。取得時の実際のチャンクIDにはランダムなリース値が含まれるため、元の出典チャンクそのものはハッシュから特定できず、出典ページ上の**全候補**を網羅している。残り予算による短縮はこの診断では再現していない。

- 10問すべて、実際に出典として選ばれたページの**どの候補抜粋でも一致しない主題が少なくとも1つ**あった。したがって、主題抽出と文字列照合がpartialに寄与した強い証拠である。実際の実行で当該条件だけが唯一の原因だったか、あるいは短縮等の影響までは確定していない。
- この10問では意味の判定はshadowだったため、意味の判定による降格ではない。
- 指定根拠が半分だった1問は、不足する側のページが意味検索、キーワード検索、融合、リランカー入力には現れたが、最終出典には含まれなかった。ページ単位の追跡であり、その候補チャンク自体に必要なアンカーがあったか、なぜ選択されなかったかは未確認。
- 9問で指定根拠を取得できた事実は、回答に必要な情報の完全性を保証しない。5件の出典を返したケースもあり、単純にpartialを解除する修正の安全性は証明されていない。

追加診断は保存済みのローカルデータのみを使用し、モデル呼び出し・質問文の記録・検索結果の変更はない。異なる資料の候補として国土地理院の公開防災教材を調べたが、まだ資料の選択・固定質問の作成・測定は行っていない。
