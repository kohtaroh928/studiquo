## 修正

同じ項目の両対象の数値が確認できる比較では、数値を並べるだけでなく、どちらがどれだけ違うかを単位付きで示す。同値は差がないと述べる。単位と比較条件が対応しない場合や片側不明では差分を推測しない。部分比較でも既知の項目の比較は残す。

指標を計算する場合は分子・分母・単位・比較基準を説明する。購入価格を記載の点灯時間で割った指標を、利用料金/電気代/維持費とは呼ばない。比較の結論を出せない場合、未依頼の片側指標を参考として追加しない。ただしユーザーが指標計算を明示的に求めた場合、意味と限界を示して計算できる。資料に明記された利用料金/電気代の説明は保持する。
