# 別資料によるRAG探索評価（2026-10-23）

## 方法

[実行前登録](RAG_SECOND_MATERIAL_PREREGISTRATION.md)の固定質問44問（答えあり29、答えなし15、比較・2主題5）を、国土地理院の地理教材で測定した。最初の実行は依存ライブラリが見つからずモデル呼出し前に終了し、依存関係を準備してから `shadow` と `on` を各1回実行した。質問としきい値は変えていない。各測定は完走し、検索時の埋め込み失敗・締切疑いは0件。判定のタイムアウトはshadowで1件、onで0件だった。独立した2回の検索なので、検索結果や判定の揺れが差に含まれうる。

| 指標 | shadow（判定は記録のみ） | on（判定を適用） |
|---|---:|---:|
| 答えあり：grounded | 22/29 | 19/29 |
| 答えあり：partial | 5/29 | 8/29 |
| 答えあり：insufficient | 2/29 | 2/29 |
| 答えあり：期待した全根拠の取得 | 27/29 | 27/29 |
| 比較・2主題：partial | 5/5 | 5/5 |
| 比較・2主題：期待した全根拠の取得 | 5/5 | 5/5 |
| 答えなし：出典を返さない | 12/15 | 15/15 |

答えなしのうち、shadowで出典が返った3問は、onで判定によって停止した。答えありでは、判定の適用で新たに停止した質問はなかった一方、3問がgroundedからpartialになった。3問はいずれも期待根拠を取得しているが、それだけでは部分回答が誤りかどうかは断定できない。別の2問は判定が呼ばれる前に両設定で停止しており、今回の意味判定による誤停止ではない。判定の呼出しは両設定30/44件（shadow成功29・タイムアウト1、on成功30）。

比較5問はすべて期待根拠を取得しながらshadow時点でpartialとなった。前回の気象教材と同様の現象だが、追加診断では、5問とも主題抽出結果の少なくとも1つが、出典ページの全文には一致しなかった（うち1問では3主題に分割）。全文での照合は実際に渡された抜粋の再現ではないため、共通原因を確定するには取得抜粋をさらに調べる必要がある。出典がないことは最終回答の正しさを保証しない。答えなしの正解ラベルは抽出本文のキーワード不在に基づき、言い換えや図中に答えがある可能性を排除できない。

本文・質問文は報告に含めない。質問・教材・生の集計は `~/.studiquo-private/rag-geography-v1/` に非公開で保存。実行環境はローカルFTS5・コサイン検索の代替と実際のWorkers AIであり、最終回答の生成、実運用のVectorize、PDF取り込み、iPadは未検証。29問・15問という小さな単一教材の探索結果から、本番有効化の可否は判断できない。既存v7の事前登録判定には加えない。
