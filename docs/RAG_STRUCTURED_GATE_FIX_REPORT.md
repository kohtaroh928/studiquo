# 料金・時刻表・部分比較の根拠判定修正

2026-10-14。Standardの局所的な不具合修正。作業先はrag-wip。3件の合成問題で、資料に存在する根拠を回答前の判定層が落とす問題を修正した。APIの実回答評価ではない。

## 修正と受け入れ条件

| 問題 | 変更後の検索後状態 | 主な修正 |
| --- | --- | --- |
| e50-versions-01 | grounded | 質問の対象と日付・参加費を分離。明示された旧版/新版の連続する開催適用期間と料金を同じ段落で確認 |
| e50-pages_tables-02 | grounded | 出発時刻と料金を別要求として確認。対象の時刻表見出し・列数・方向の行・各列の具体値を対応させる |
| e50-partial-03 | partial | 共通属性の「と」を対象区切りにしない。E/Fの限定されたアルファベット型番省略を復元。両対象の点灯時間と片側の価格があれば部分回答へ進む |

元の資料本文は変更せずcontextへ渡す。structure-aware chunking・検索モデル・RRF順位は変更していない。正しいsourceId/pageNumberの構造化出典を保持する。partialは完全な価格比較やお得さを確定できるという意味ではない。資料外の価格を補うことは許可していない。

## 保守的な境界

- 価格だけの比較は従来どおり両対象の具体価格を必要とする。点灯時間＋価格の比較でも、両価格不明・片側の点灯時間不明・別対象の価格だけでは今回のpartial経路に進めない。
- FとF2を混同しない。短縮対象の復元は先頭対象のアルファベット末尾と後続の単独アルファベットという限定形のみ。任意の日本語対象へ共有修飾語を推測しない。
- 日付の料金要求では、日付のない同年の価格だけを根拠にしない。無効な暦日も拒否する。独立レビューで通常価格経路による迂回を見つけ、回帰テストとともに塞いだ。
- 限定された構造化経路で扱えない温度・追加年度・名前付き法則の条件は無視しない。独立レビューで見つかった条件の見落としも修正した。
- 表は同一の短いブロック内の完全な見出しと3列を必要とする。同じ方向の重複行、欠落値、無効時刻、別表、別対象の表、値に命令を混ぜたセルは支持しない。
- 本人フィルタ、source認可、Locked除外、削除、scope、prompt injection方針、同意、課金、ログ、RAG無効時の通常チャットは変更していない。
