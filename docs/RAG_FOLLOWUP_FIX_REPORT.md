# 追加質問の評価と続きの質問の修正（2026-10-09）

## 追加評価と修正

指定114ページPDFの別ページをPDFKitで目視確認し、追加22質問（答えのある質問12、続きの質問2、資料外4、同じ話題だが価格/型番がない質問2、確認が必要な曖昧質問2）を実行前にprivate領域へ固定した。

初回、14件すべてで必要ページが検索候補に入ったが、1件の続きの質問はlexical eligible条件で除外された。Query Rewriteが「対象についてもっと詳しく」と正しく組み立てても、importantTextが「詳しく」だけを除き、「もっと」が検索語に残った。短い略語を主題にすると関係のないbigramが比率を下げ、正しい根拠を除外していた。

「もっと詳しく」の後ろが文末・空白・句読点・明確な説明依頼である場合だけ依頼表現を除くよう修正した。質問のcanonicalQuery・主題・条件・具体情報の要求は保持する。「もっとも小さい」「もっと大きい」「もっと詳しく学ぶ」は今回の除去対象にしない。関連性のしきい値を下げていない。
