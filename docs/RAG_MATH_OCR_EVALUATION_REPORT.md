入力：[気象庁『総観気象学 基礎編 改訂版』](https://www.jma.go.jp/jma/kishou/know/expert/pdf/textbook_synop_basic_revision_20250331.pdf)、物理40ページ／印刷34ページの5式。周辺本文・式番号を除いた切抜き。正解は拡大画像を二者で確認した。初期転記のΔとd、および≡と=の誤りを画像根拠で修正しており、推論結果との単純一致を採点基準にしていない。式4のVの字体・weightは確定困難のため主要構造の採点と分離した。字体判定可能な4式についてGeminiは4/4、pix2texは3/4。

## 採点と再現性

自動採点はLaTeX空白・括弧サイズ指定・分数表示スタイルだけを正規化する。command境界、添字、分子分母、符号、変数、微分、字体命令を保持する。無害なbrace差を許容する目視構造判定と、自動文字列一致は別物であり、上表は独立目視構造判定。代数的な簡約や変数置換で誤式を正解化しない。

画像、正解、認識本文、API応答、端末情報、モデル環境、実機プロジェクト、実行ログはprivate一時領域に保存。リポジトリには本文・キー・端末識別子を追加していない。外部送信は今回の公開教材の数式画像のみ。pix2texは隔離venvで実行し、アプリの依存関係には追加していない。

検証：Worker全体760/760成功（追加境界テスト前）。最終版の評価専用テスト12/12成功。独立レビューでcommand境界が空白除去により失われる問題を発見し修正・回帰テスト追加。iOS製品コード未変更のため、この評価でアプリ全体テストは再実行していない。
