# 根拠段落の網羅指示の修正と実測（2026-10-11）

**評価用の段落選択指示を修正し、数式ケースの単位の取りこぼしを今回の実Gemini測定で解消した。** 数式の根拠段落は4/5から5/5へ改善し、他の2ケースも必須情報を保持した。最後の1ケースはHTTP503で未評価。本番に接続した変更ではなく、少数の合成資料での確認結果である。

## 修正内容

旧`baseline`指示はそのまま残し、新しい`complete`方針を追加した。

1. 選んだ根拠段落全体で、質問が明示的に求める各要素を覆うよう指示する。代表的な段落だけでは足りない。
2. 式・記号・単位・前提・適用範囲・例外・否定・比較対象を具体的な根拠として含める。
3. 導入や概要で枠を使い、必要な具体説明を押し出さない。導入を一律に削除する処理は追加しない。
4. 全文保持を根拠段落の網羅の代わりにしない。必要情報が不足・不確実、または1参照3段落では足りなければabstainし、既存処理でbaseline全文を保持する。

新方針の「不確実ならabstain」と旧方針の「不確実ならretain」が競合しないよう、旧文は新方針では置き換える。JSON schema・3段落の上限・5秒制限・prompt injection対策・出典の構造・safeReferences・productionEligible=falseは変更しない。

モデルの自己判断が完全性を保証するわけではない。評価側では独立した暫定ラベルで必要情報を測り、`requiredCoverageStatus`をcomplete／incomplete／not_evaluatedとして記録する。completeは定義済みラベルの被覆だけを意味し、意味的完全性や本番の品質保証ではない。構造上は成功しても単位が抜けた模擬応答はincompleteとなる。abstain・API障害はnot_evaluatedで、品質の分母に含めない。

| 比較・暗所の否定・夜の呼吸 | 4/4 | 4/4、ラベル被覆complete | 3.262秒 |

新方針の4要求中3件がHTTP200/STOP、modelVersion Gemini3.6。成功した3件の全文とwitnessの必須情報は12/12、保護条件欠落0。最後の503で停止し、追加送信はしていない。旧方針の例外条件4/4を新方針の成功へ流用しない。

数式では、以前のr1_p1/p2/p3からr1_p2/p3/p4へ変わり、導入の代わりに単位を選べた。別ページの適用例外も維持した。r2_p1という導入も残るが、必要情報を押し出していない。未ラベルの段落を無関係とは断定しない。

旧結果と新結果では実行時刻が異なり、サービスの状態や確率的な出力の変動もある。単発比較で、指示だけが改善原因だったことや繰り返しの再現率を確定できない。合成stress資料・人間/教師未確認ラベル・blindでない評価であり、一般精度100%ではない。最終回答・実教材・一連のCloudflare検索は今回未評価。

修正後の成功3ケースは選択参照数・全文量を減らしていない。本文の切り詰め・出典削減・費用削減を実現した変更ではない。段落選びの評価用指示の改善であり、製品のcontextはbaselineを保持する。

## 実験分離・安全

固定profile `multiparagraph-complete` を追加。旧既定のpromptと実験identityを維持し、新方針は実際のmessagesを含む別hashにする。異policyのstateはキー読み込み前に拒否する。旧結果・旧stateは書き換えない。

新stateは `/private/tmp/studiquo-multi-complete-state.json`、結果は `/private/tmp/studiquo-multi-complete-live-20261011.json`。初期化時は既知quota期限と由来の3項目のみ継承し、成功行は引き継がない。現在の新stateは構造成功3件、例外条件1件が未完了。形式完了と品質合格は引き続き別である。

APIは4call、31秒間隔、各5秒、run内の自動再試行なし、認証・429・5xxで停止。キー・prompt・資料本文・生モデルJSON・自由エラー文を新規保存していない。暫定ラベルはGeminiへ送らず、client側の採点だけに使う。固定送信先、redirect拒否、サイズ上限、credential alias拒否、atomic0600保存、lockを維持した。

成功3callのusageは入力2,122・出力475・total2,597 tokens。503の使用量・実請求額・billing tierは未確認。新指示の入力は対応する旧ケースより各143 tokens増えた。費用0とは断定しない。
