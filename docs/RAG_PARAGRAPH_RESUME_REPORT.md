## 手動再開

`mcp-server`で実行する。キー値はコマンドに入れない。第1引数は状態、第2引数は詳細結果の保存先。

```sh
STUDIQUO_RAG_PROPOSAL_REMOTE=true STUDIQUO_RAG_KEY_FILE=/path/to/existing/.dev.vars node scripts/rag-quality/paragraph-resume.mjs /private/tmp/studiquo-paragraph-resume-state.json /private/tmp/studiquo-paragraph-resume-result.json
```

待機中や全問題が完了済みの場合はAPIを呼ばない。再開時は未完了の問題のみ、31秒間隔、各5秒で評価し、認証・429・5xxで停止する。キー・状態・結果・予約ロックの同一パスやaliasを拒否し、状態は0600の一時ファイルから原子的に置き換える。

同じ状態を使う同時実行はロックで拒否する。強制終了では `.lock` が残る場合があるため、稼働プロセスがないことを確認してから手動で解消する。自動で古いロックを消さない。私有一時ファイルはOSが削除する可能性があるので、後日使う場合は安全なローカル領域へ状態を保持する必要がある。

応答直後に問題IDを保存するため、中断後に成功済み分を再送せずに再開できる。ただしAPI応答と保存の間に強制終了すると再送が発生しうる。厳密な一度だけの課金を保証しない。詳細token・応答時間のreportは正常終了時に保存し、中断した実行の詳細usageは状態から復元できない。
