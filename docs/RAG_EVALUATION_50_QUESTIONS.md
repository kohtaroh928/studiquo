# RAG未使用50問の一覧

2026-10-13。すべて新規の固定合成資料による評価用質問。作成時はAIへ未送信。現在は調整用30問を両styleで回答層評価済み。正解の人間確認は未完了。作成/レビュー担当は内容を見ているため盲検ではない。

正本は `mcp-server/scripts/rag-quality/evaluation-50.json`。資料・項目ごとの期待結果・引用根拠・禁止主張を含む。条件を明記した資料と自然な不足/矛盾の資料が混在しており、実資料全体の難しさを再現したセットとは主張しない。

各分野の最初の3問は調整用、後ろ2問は未使用確認用。後ろ2問を調整へ使ったら、別の確認用問題へ交換する。50問をsource_only/explain両方で評価すると100回答。
