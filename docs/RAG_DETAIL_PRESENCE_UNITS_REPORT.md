## 変更

1. **金額の単位を足した。** 「何円」「何万円」「何億円」「何ドル」を聞く質問では、根拠に金額（数字＋円／ドル）があることを確認する。5826億円は「何万円」の答えにもなるので、規模（億・万・千・兆）は聞く側も書く側も任意にした。
2. **数値を質問の対象に結びつけた。** 単位を聞く質問で、その単位の数値は、**1位の根拠にある**か、**質問の固有語（カタカナ語・英字の語。単位名を除く）を含む根拠にある**ときだけ有効にする。無関係な2位以下のページに、同じ単位がたまたまあっても通らない。固有語のない質問では、1位の根拠だけが有効。比較の質問（複数の対象）は結びつけず、従来どおり全体で確認する。単位を指定しない質問（いくつ、どれくらい）も従来どおり。

## 直らなかった1件と、その理由

「台風第19号の損害保険金は、1件あたり何万円か」は、金額の単位（円）を足しても **直っていない**。1位のページに、**別の対象**（地震）の金額（12,896億円など）があり、単位としては合っているため。この種類の誤りは、金額が質問の対象（台風第19号、1件あたり）の記述にあるかを、文の単位で確認しないと防げない。今回の範囲を超えるので、直していない。

## 限界

1. **未見39問は、前回の確認で「調整済み」になった。** 今回の+1件は、原因を見てから直したもので、汎化の証拠ではない。回帰（合成60問・validation・第2回・未見39問で悪化なし）の確認としては有効。
2. **別名に弱い。** 数値が1位でない根拠にあり、質問の固有語が資料で別の言い方になっている場合（例：質問は「アメリカ」、資料は「米国」）は、数値があっても有効にならない。今回の4つの評価では起きていない（該当の質問は、数値のあるページが1位）。実際の資料では起きうる。
3. **固有語がない質問は、1位の根拠だけが有効。** 数値が2位以下にしかない正しい質問は、落ちうる。今回の評価では起きていない。
4. 狙った範囲は、単位つきの量だけ。単位のない詳細（理由・方法・固有名詞）、英字の固有語、普通の語を含む無関係な質問は、未対応のまま。
5. 「出典を抑える」と「資料にないと正しく答える」は別で、最終回答は未測定。
