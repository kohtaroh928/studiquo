日付: 2026-10-11。作業先: `.worktrees/rag-wip`、ブランチ: `codex/rag-wip`。

## 目的・範囲

資料への忠実さを保ちながら、初心者の理解に必要な背景説明を区別して許可する。今回の縦切りはWorkerの回答styleと4組の評価問題・API経路テストのみ。iOS UI、自動索引、認証・同意、検索・出典、設定・デプロイは変更していない。

任意入力`rag.answerStyle`は`source_only`または`explain`。明示的な`explain`だけが解説を有効にし、未指定・未知値・無効型はsource_onlyに正規化する。任意の入力文字列を固定指示へ挿入しない。旧クライアントは従来の指示のまま。

`grounded`/`partial`の解説では、資料の事実・条件・例外を先に保持し、必要な基本用語・前提・考え方を「理解のための補足」などで区別する。補足に資料出典を付けたと主張しない。不明な固有仕様・料金・数値・係数・指数を補わず、仮定の例を資料の値と混同しない。

初期段階の`insufficient`/`clarification`はstyleにかかわらず既存方針を維持する。一般的な背景だけを安全に切り出して答える能力は、根拠不足時についてはまだ追加していない。検索0件・障害・同意なし・RAG無効時も通常チャットを維持する。

## 独立レビュー

Plannerが、解説をgrounded/partialに限定し、根拠不足時は既存維持、未指定は完全互換とする方針を検討した。Code Reviewerが今回の5つのコード・評価ファイルを読み取りレビューし、重大な問題なし。追加した通常チャット用生成関数・採点基準除外テストも再レビューし問題なし。

レビューは一度利用上限で中断したが、その後再開して完了した。実モデルの説明品質と未知値非補完・不正命令耐性は残件として指摘された。
