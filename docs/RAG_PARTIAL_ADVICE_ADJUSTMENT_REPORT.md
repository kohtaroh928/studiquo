# 部分比較の助言と不要な不足説明の調整

2026-10-13。前回の比較の未表示一般助言と、密度の不要な条件未記載節を受け、固定回答policyを局所調整した。

## 修正

- explainの一般的な使い方/選び方助言は、最初の助言より前に補足表示。資料の既知使用条件を確認/言い換える説明と区別。
- 資料にある条件/例外は必須保持、未記載条件は推定しない。条件有無の明示質問や適用判断に不可欠なときだけ未確認と説明。それ以外の条件未記載節は抑制。
- 資料の式や単位の分子分母を直接言い換える説明は資料に基づく説明として許可。一般知識の性質/用途/たとえ追加と区別して学習に必要な理解を維持。
- partialで未知対象の仕様を埋めず、比較全体から優劣/最適/おすすめを確定しない。既知対象の条件が用途に合う説明は許すが、両者比較の選択結論として提示しない。
