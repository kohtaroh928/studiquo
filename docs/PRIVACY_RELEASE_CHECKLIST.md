# プライバシー変更の公開手順

更新: 2026-10-05。開発ブランチで実装した内容であり、本番反映は未実施。

## 実装した設定

- AIは初期提供先をGoogle一社に限定。送信内容の説明後、バージョン付き許可が必要。拒否しても通常のノート機能は使える。
- 開いているノートを自動送信しない。質問・会話履歴と、利用者が選んだ資料だけを送る。
- 翌日AI復習・自動診断は初期OFF。旧版の設定を新しい許可へ自動移行しない。
- 問題報告の画像も初期OFF。本文・画像の閲覧は管理者ログイン必須。Slackには通知情報とリンクのみ。
- 問題報告・画像・個人に紐づく購入イベント・診断との関連は90日を削除対象にする。匿名エラー集約は最終発生から180日。
- 退会はサーバーの永続削除ジョブ受理後に端末削除へ進む。失敗後も再試行可能。RevenueCat顧客削除も永続ジョブで再試行する。App Store購読の解約は別操作。
- 端末の学習データとアプリ管理ファイル、共有Inboxを消去する。ファイルアプリの原本・他の人の会話履歴・Apple IDの別バックアップまでは消去しない。

## 公開前の必須条件

1. D1をバックアップし、テスト環境で追加migration `0005_privacy_retention.sql`を適用して検証する。その後、承認を得て本番migration→Worker→アプリの順に更新する。新Workerは追加列・テーブルを要求するため、順序を逆にしない。
2. `REVENUECAT_SECRET_API_KEY`を秘密管理へ設定する。顧客削除APIの権限とテスト用顧客での削除を確認する。本番顧客をテストに使わない。
3. migrationと削除テスト確認後、`PRIVACY_RETENTION_ENABLED`をtrueにする。定期実行は毎時、各種類100件まで。期限経過直後の物理削除を保証する方式ではなく、次の実行で順次処理する。
4. `privacy retention backlog requires attention`警告を監視・通知対象にする。未処理が増える場合は容量・頻度を見直す。各種類2,400件/日以上の期限到来は現設定の処理量を超える。大量の旧データは本番公開前に承認済みの移行作業で処理する。
5. 外部削除待ちの間は同じidentityで再ログインできない。削除完了後の再登録・旧課金Webhookとの区別・D1削除済み識別子の保持期限は未確定であり、公開前に世代管理を含む再登録方針を決める。削除済みアカウントの課金通知は現状無視する。
6. Google Geminiの対象年齢・学生向け提供可否、契約、モデル訓練利用、保存期間を確認する。確認完了まで`AI_PROVIDER_APPROVED=false`を維持する。単にtrueにするだけでは契約上の問題を解決しない。
7. Sign in with Appleの認可取消し、共同編集データの削除範囲、CloudKit実機同期削除を確認する。現状の技術変更だけで公開可能と判断しない。
8. Privacy Manifestの分類をApp Store Connectのプライバシー申告と照合する。アプリ内・Webの説明、実際の外部サービス契約を責任者が確認する。
9. 既にSlackへ投稿した本文・画像、期限切れセッションで所有者を復元できない旧問題報告は、別途運営による整理が必要。自動削除済みとは説明しない。

## 互換性とロールバック

旧アプリには新しいAI同意ヘッダーがないため、新WorkerはAI送信を拒否する。通常の学習機能は継続可能。新アプリは退会APIの200/202を成功受理として扱う。削除処理は実データを消すため、コードを戻しても削除済みデータは戻らない。

異常時はAI承認フラグをfalseにする。削除ジョブ停止が必要な場合のみ保持フラグをfalseへ戻し、停止中の削除要求を監視する。migrationは追加型なので列・テーブルを削除して戻さない。旧版へ戻すと新しい同意・削除制御が失われる点に注意する。

## 検証の制約

ローカルのAPIテスト、iPadシミュレータの関連テスト、独立セキュリティレビューを実施する。本番migration、外部顧客削除、App Store申告、契約確認、実機CloudKit検証は別工程であり、この実装作業では実施しない。

2026-10-05の検証: サーバー`npm test`は508件成功。iOSはAI同意・トーク・モデル選択・翌日復習・退会・診断・旧direct採点拒否の関連テストを実行し、署名付きシミュレータで成功。署名なしの初回実行では既存Keychain fixtureが権限エラー(-34018)となり、署名付きで再確認した。Privacy Manifestの構文と差分チェックも成功。独立レビュー指摘に基づき、共有Inbox削除、課金Webhook競合、期限切れ表示、外部削除待ちの別名ログイン制御を修正した。
