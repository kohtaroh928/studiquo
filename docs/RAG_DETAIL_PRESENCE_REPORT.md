# 答えなし判定の修正：求められた詳細が本文にあるかを確認する

2026-10-21。[実資料の第2回評価](RAG_REAL_MATERIAL_V2_REPORT.md)で、答えがない6問のうち出典を抑えられたのが2/6だった。話題が合うだけで、質問が求める詳細が本文にあるかを確認していなかったため。その確認を2つ足し、合成60問・validation 20問・実資料第2回の30問で回帰を確認した。対象は `claude/rag-ts`。非本文の集計は[RAG_DETAIL_PRESENCE_RESULTS.json](RAG_DETAIL_PRESENCE_RESULTS.json)。

## 結論

- 実資料第2回で、答えなし6問の出典抑制が **2/6 → 6/6**。答えがある24問は22/24のまま（取りこぼしも誤判定も増えていない）。
- 合成60問（正解あり55問で必要ページが55/55、答えなし5問は出典なし）とvalidation 20問（10/10、否定10問は出典なし）は、**修正前と同じ**。
- **6/6は、失敗の中身を見てから直した結果であり、汎化の証拠ではない。** 未見の答えなし質問での確認が次に要る。
- **追記（同日）**：未見の答えなし質問27問で確認した（[RAG_DETAIL_PRESENCE_GENERALIZATION_REPORT.md](RAG_DETAIL_PRESENCE_GENERALIZATION_REPORT.md)）。出典の抑制は9/27→17/27で、効いたのは狙った範囲（単位つきの量、資料にないカタカナ語）。それ以外はほぼ変わらず、答えなし判定は全体としてまだ弱い。

## 足した確認（`mcp-server/src/rag/detail-presence.ts`、`retrieval.ts`）

最終の根拠が決まった後、認可の確認の前に、2つを確認する。どちらも出典を**減らす**だけで、足すことはない。既存の根拠チェック（`answerability.ts`）は変更していない。

1. **求められた量があるか。** 質問が「何%」「何件」「何m/s」「何度」「何倍」などの単位を聞いているとき、根拠の本文にその種類の数値（例: 数字＋％／パーセント／割）があることを確認する。単位を指定しない「いくつ」「どれくらい」は、何らかの数字があればよい。複数の単位を聞くときは、どれか1つあればよい。なければ状態は `insufficient`（出典なし）。
2. **質問の固有語が資料にあるか。** 質問中の3文字以上のカタカナ語（「メカニズム」などの一般語を除く）が、最終の根拠にも取得した全候補にもなく、さらに**検索範囲の全文にも出てこない**とき、その根拠では答えられないと判断する。質問の残りの語が根拠と重なるなら `insufficient`、重ならなければ `no_match`（通常チャットへ）。長音符の有無（コンピュータ／コンピューター）は区別しない。ただし**意味検索と語句検索が同じ抜粋を1位にしているときは行わない**（下記）。範囲の確認に失敗した場合は、根拠を消さない。

## 試した方法と、採らなかった理由

| 版 | 内容 | 結果 |
|---|---|---|
| 初版 | 固有語が検索範囲にないとき、無条件で根拠を消す | 実資料6/6だが、合成60問で**1件悪化**（言い換えの質問「プール」→資料は「水」が、資料にない語として落ちた。55/55→54/55） |
| リランカー併用 | 固有語がなく、かつリランカーの最高スコアが0.03未満のときだけ消す | 同じ1件が悪化。**リランカーは日本語の言い換えにほとんど反応しない**（合成の正解あり55問のうち12問は、最高スコアが0.005以下）うえ、2秒で時間切れのときは条件が働かず結果が不安定。採用しない |
| **採用版** | 意味検索と語句検索の1位が同じ抜粋なら、固有語がなくても言い換えとして残す | 合成60問・validationは変化なし、実資料は6/6 |

採用した条件の根拠：言い換えの質問では両検索が同じ抜粋を1位にしていた（上の例は35ページ）。答えなしの質問では1位が食い違っていた（「ラニーニャ」の質問は意味検索270ページ・語句検索303ページ、「カレー」の質問は340ページと3ページ）。

## 限界

1. **6/6は調整済みの結果。** 第2回の失敗4件を見てから条件を作った。未見の答えなし質問（話題が合うが詳細がない、無関係、固有語が資料にない）で測り直す必要がある。
2. **効く範囲は狭い。** 1つ目は単位つきの量を聞く質問だけ、2つ目はカタカナ語だけ。漢字語の固有名詞が資料にない場合、単位のない詳細（理由・方法など）が資料にない場合は、今回の条件では防げない。
3. **意味検索と語句検索の1位が一致すると、固有語の確認を行わない。** 答えなしの質問で偶然両方が同じ抜粋を1位にすると、出典が付きうる。
4. **「資料にない」ことの判定は検索の段階まで。** 最終回答のAIがどう答えるかは測っていない。
5. **答えがある質問の弱点は直していない。** 複数の数値条件を同時に求める質問が根拠不足と判断される1件、別ページの2主題の比較で片方が落ちる1件は、第2回のまま。
6. 実Vectorize／実D1、実iPad、手書き・紙スキャン、最終回答は含まない。
